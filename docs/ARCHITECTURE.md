# 架构设计（ARCHITECTURE）

> forge-1024 · AI 微指令内核 · 内核版本 1.0.0 / 编目版本 2026.10

---

## 1. 总体形态

forge-1024 是一个**指令集架构（ISA）风格的 AI 内核**：把 AI 的全部基础能力拆成 1024 条**微指令**，每条是纯函数 + 元数据，由统一注册表调度。

```
┌──────────────────────────────────────────────────────────────┐
│                        用户 / 示例 / 工具                      │
└──────────────────────────┬───────────────────────────────────┘
                           │ exec(name, args) / tryExec
┌──────────────────────────▼───────────────────────────────────┐
│  D10 SYS   系统编排：内省 / 遥测 / 验证 / 文档生成 / 基准 / 图  │
├──────────────────────────────────────────────────────────────┤
│  D9 TRAIN  训练与评估：数据管线 / 训练循环 / CV / 可复现性      │
│  D8 DL     深度学习：层 / 注意力 / RNN / 损失 / 初始化          │
│  D7 ML     机器学习：回归 / 分类 / 树 / 集成 / 聚类 / 降维      │
├──────────────────────────────────────────────────────────────┤
│  D5 OPT    优化器    │  D6 PROB  概率统计                      │
├──────────────────────┴───────────────────────────────────────┤
│  D4 AUTODIFF  自动微分：磁带反向模式 / 对偶数前向模式 / 梯度检验 │
├──────────────────────────────────────────────────────────────┤
│  D3 LINALG  线性代数：分解族 / 求解器 / 迭代法 / 矩阵函数        │
│  D2 NUM     数值方法：稳定化 / 补偿求和 / 求根 / 积分 / 特殊函数 │
│  D1 MATH    数学基元：逐元素 / 归约 / 范数 / 构造器              │
├──────────────────────────────────────────────────────────────┤
│  内核 core：Tensor（广播/归约）· RNG（PCG32）· Registry · 遥测 · 错误分类学 │
└──────────────────────────────────────────────────────────────┘
```

依赖方向严格自下而上：`D1 ← D2 ← D3 ← D4 ← {D5, D6} ← D7 ← D8 ← D9 ← D10`。
**D10 只依赖注册表**，因此它能反过来校验整个编目（自举自检）。

## 2. 内核五件套（src/core）

| 模块 | 职责 | 关键设计 |
|---|---|---|
| `tensor.mjs` | N 维张量 | Float64Array 后端 + shape/strides；广播与归约遵循 **NumPy 语义**（含 keepDims） |
| `rng.mjs` | 确定性随机 | **PCG32**（`createRng(seed)`）；全局禁用 `Math.random`，保证逐位可复现 |
| `registry.mjs` | 指令注册与调度 | `defineOp` 元数据校验 → `exec` arity 校验 → 调用 → 遥测 → 错误归一化 |
| `errors.mjs` | 错误分类学 | `ForgeError` + `CODES`：`E_SHAPE / E_VALUE / E_TYPE / E_NUMERICAL / E_ARITY / E_NOTFOUND` |
| `telemetry.mjs` | 遥测 | 调用计数 / 错误计数 / 可选计时（默认关计时以免污染微基准）/ 追踪 |

### 2.1 指令的定义

```js
defineOp({
  id: 'D3-042',                       // D<域>-<三位序号>，每域 001..102
  domain: 3,                          // 域编号
  name: 'linalg.cholesky',            // 全局唯一，带域前缀
  arity: 1,                           // = impl 形参个数（exec 严格校验）
  sig: '(Tensor A) -> Tensor L',      // 签名
  doc: 'Cholesky 分解 A = LLᵀ（A 对称正定）',
  ref: 'Cholesky；Higham, Accuracy and Stability of Numerical Algorithms, 2002',
  inv: 'L 下三角且 LLᵀ = A；L 对角元全正',
  impl: (A) => { /* ... */ },
});
```

`defineOp` 强制校验 8 个必填字段，并拒绝**重复 id 与重复 name**——编目的一致性由注册器本身保证，而不是靠约定。

### 2.3 arity 契约

`arity` 必须**严格等于 `impl.length`**（含可选参数）。`exec` 在调用前校验 `args.length >= arity`。
这条契约让「反射式模糊测试」成为可能：任意指令都可以被自动构造入参调用并断言「只可能抛 ForgeError，不可能抛 TypeError」。

## 3. 十域划分的动机

1024 = 6×102 + 4×103，不是巧合：

- **10 域**对应 AI 能力的十个正交切面（数学 → 数值 → 线代 → 微分 → 优化 → 概率 → 经典 ML → 深度学习 → 训练工程 → 系统编排），覆盖从底层算术到顶层编排的完整栈。
- **每域 ~102 条**强制各域**均衡**，避免某一域膨胀成杂物抽屉；新增能力必须先归入某个域并挤掉/合并一条现有指令，从而抑制无节制扩张。其中 6 个基础域各承载 102 条，能力面最广的 4 个域（ML / DL / TRAIN / SYS）各多承载 1 条（103），合计 **6×102 + 4×103 = 1024**。
- 每域文件末尾有**自检**：`if (opsByDomain(N).length !== EXPECT) throw`——不满足则模块加载即失败，编目不可能处于「半成品」状态。

## 4. 不变量体系（本项目的灵魂）

每条指令的 `inv` 字段是一条**可被独立实现交叉验证的数学性质**。测试策略按不变量类型分类：

| 类型 | 说明 | 代表 |
|---|---|---|
| 解析 ↔ 数值 | 闭式解与迭代/分解解一致 | 线性回归四解一致 |
| 双路径一致 | 两条独立算法给出同一结果 | Jacobi 谱 == SVD 谱 |
| 定理级性质 | 经典定理的可计算推论 | EM 似然单调不减 |
| 差分检验 | 解析梯度 vs 中心差分 | gradcheck < 1e-6 |
| 结构不变量 | 分解结果的代数结构 | `QᵀQ = I`、`LLᵀ = A`、协方差对称半正定 |
| 概率公理 | 归一化 / 非负性 | `Σp = 1`、`KL ≥ 0` |
| 计算等价 | 优化实现 == 朴素实现 | KV-Cache 增量 == 全量因果注意力 |
| 单调/收敛 | 优化器的收敛性 | 16 个优化器在凸二次上收敛 |

## 5. 数值稳健性策略

| 风险 | 对策 |
|---|---|
| `exp` 溢出 | 全部 softmax / logsumexp 减最大值 |
| 累积舍入 | Kahan / Neumaier / pairwise 补偿求和；twoSum/twoProd double-double |
| 协方差奇异 | Cholesky 前加 ridge；`nearestSPD`（Higham 算法）修复非正定 |
| 特殊函数精度 | gamma 用 **Stirling 级数 + 递推**（~1e-15）而非 Lanczos 近似（~1e-10）；erfc 用 Laplace 连分式 |
| 病态系统 | 提供 SVD/QR/Cholesky 三条独立路径，可交叉验证 |
| 除零 / log(0) | 统一 eps 保护，且 eps 可配置 |
| 随机不可复现 | 全局 PCG32，禁用 `Math.random` |

## 6. 自动微分设计

- **反向模式（磁带）**：`tape` 全局数组 + `record(name, inputs, out, vjp)`；`ad.backward(loss)` 逆序回放，梯度沿多路径自动累加。广播的逆操作由 `sumTo` 完成（对多出前导维与被广播的 1 维求和）。
- **前向模式（对偶数）**：`(primal, tangent)` 对，用于 Jacobian–vector 乘积与高精度方向导数。
- **梯度检验**：`ad.gradcheck / gradcheckVec` 用中心差分对照，相对误差阈值 1e-6——**所有可微算子都必须通过**，这是 vjp 正确性的硬金标准。

---

## 7. 组合性

指令之间的组合不是靠继承或对象，而是靠**纯函数 + 统一调度**：

```js
exec('sys.exec.pipe', [
  [{ op: 'math.add' }, { op: 'math.mul', args: [2] }, { op: 'math.sum' }],
  x,
]);
```

D10 提供 `sys.graph.*` 做 DAG 编排（拓扑排序 + 环检测 + 按序执行），可用于把 1024 条指令拼成任意计算图。

---

## 8. 可复现性设计

1. **随机源唯一**：`createRng(seed)`（PCG32），无 `Math.random`。
2. **state 可序列化**：优化器 / 模型 state 一律为纯对象 + 普通数组（不用 Float64Array），可 `JSON.stringify` 后落盘与回放。
3. **实验指纹**：D9 的 `train.repro.fingerprint / manifest / manifestHash` 给出参数 + 数据的稳定哈希，`assertReproducible` 断言同种子同结果。
4. **遥测可导出**：调用计数与耗时可导出，用于回归对比。

---

## 9. 为什么零依赖

- **可审计**：1024 条指令全部是能读懂的 JS，没有二进制黑盒。
- **可移植**：Node ≥ 18 直接跑；同一份源码可打包成单文件 HTML 在浏览器里自检。
- **可长期保存**：无依赖树意味着十年后仍能运行（LLM 时代的「长寿代码」标准）。
- **可教学**：每条指令对应一篇论文 + 一条不变量，可直接当教材使用。

## 10. 与主流框架的对照

| 能力 | PyTorch / JAX / NumPy | forge-1024 |
|---|---|---|
| 张量 | 有（C++/CUDA 后端） | 有（纯 JS Float64Array，NumPy 广播语义） |
| 自动微分 | 有（autograd / jax.grad） | 有（磁带反向 + 对偶数前向 + gradcheck） |
| 优化器 | 有 | 有（16 个 + 12 调度 + 线搜索） |
| 概率分布 | 需 scipy / torch.distributions | 内建 17 族 |
| 经典 ML | 需 sklearn | 内建（D7） |
| 元数据/不变量 | 无（文档与实现分离） | **强制**：doc + ref + inv 三件套 |
| 依赖 | 数百 MB | **0** |
| 文档漂移 | 可能发生 | **不可能**（由注册表反射生成） |
